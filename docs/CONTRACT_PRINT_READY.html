ТЕХНИЧЕСКОЕ ЗАДАНИЕ

на разработку программного комплекса «Mentor Hub»

1. ОБЩИЕ СВЕДЕНИЯ И ЦЕЛИ ПРОЕКТА

1.1. Система представляет собой специализированный комплекс автоматизации сбора ежедневных отчетов, контроля дисциплины учениц и генерации кейсов наставника Ксении Сидоренко.

1.2. Цель разработки: высвобождение 1.5–2 часов ежедневного рабочего времени наставника за счет ликвидации ручной рутины в разрозненных чатах Telegram и автоматической защиты от сдачи недействительных/повторных видеороликов Reels.

2. АРХИТЕКТУРА И СОСТАВ ПОДСИСТЕМ

2.1. Модуль сбора данных Telegram (Telegram Ingestion Gateway):

  • Взаимодействие через Telegram Business API и Telegram Bot API;
  • Фильтрация отчетов по хэштегам: #рилс, #продажи, #рассылки, #вопрос;
  • Валидация ссылок на Instagram Reels с алгоритмом вычисления SHA-256 хеша для блокировки повторной сдачи одного и того же ролика;
  • Автоматический фоновый триггер (cron в 20:00) для отправки напоминаний ученицам с несданными отчетами.

2.2. Модуль искусственного интеллекта (AI-пайплайн):

  • Транскрибация аудиоформата .oga голосовых сообщений учениц в текстовый формат;
  • Анализ сообщений с удалением бытового флуда и структурированием ключевых метрик;
  • Автогенерация шаблона кейса для Instagram Stories на основе динамики показателей (Точка А ➡️ Точка Б, прирост дохода и кратный множитель).

2.3. Пользовательский веб-трекер наставника (React 19 SPA):

  • Экран «На проверку (Inbox Zero)» с быстрой кнопкой подтверждения отчета и переходом в Telegram;
  • Экран «Ученицы & Календарь» с цветовой индикацией дисциплины по дням недели (Пн–Вс);
  • Экран «Аналитика & Кейсы» с кнопкой быстрого копирования продающего текста в буфер обмена.

3. СТЕК ТЕХНОЛОГИЙ

Бэкенд: Java 21 LTS / Spring Boot 3.4+, PostgreSQL 16+, TelegramBots SDK 10.3.
Фронтенд: React 19, Vite, Tailwind CSS, Lucide Icons (адаптивная верстка с поддержкой Apple iPad).
