# Mentor Hub — Персональный трекер наставника & Telegram Automation

Универсальный сервис автоматизации сбора отчетов, контроля дисциплины и генерации продающих кейсов для наставника (Ксении).

---

## 📂 Структура проекта

* **`frontend/`** — Готовый интерактивный SPA веб-трекер наставника (React 19 + Vite + Tailwind CSS + Lucide Icons):
  - Оптимизирован под iPad и десктоп.
  - Нейтральный брендинг («Mentor Hub», без упоминания «Миранда»).
  - Вкладки:
    1. **🔥 На проверку (Inbox Zero)** — карточки отчетов за сегодня, валидация ссылок на Reels, обнаружение дубликатов, быстрый коммент, кнопка «В Telegram».
    2. **👩‍🎓 Ученицы & Календарь** — таблица учениц, недельная сетка (Пн–Вс) с цветовыми статусами и % дисциплины.
    3. **📊 Аналитика & Кейсы для Инсты** — расчет Точка А ➡️ Точка Б, кратный рост дохода, кнопка «Скопировать для сторис».
    4. **📋 Задания & Хэштеги** — правила сдачи (#рилс, #продажи, #рассылки, #вопрос).
    5. **💼 Тарифы разработки** — визуальная смета (320 BYN / 475 BYN).
  - Сборка: протестирована командой `npm run build` (0 ошибок).
  - Быстрый запуск: `start-demo.bat` или `cd frontend && npm run dev`.

* **`docs/ARCHITECTURE_SPRING_BOOT.md`** — Детальная архитектурная спецификация бэкенда на Java:
  - Стек: Spring Boot 4.x / Spring AI 2.x (с надёжной совместимостью со Spring Boot 3.4.x / Spring AI 1.x), PostgreSQL 16, TelegramBots 10.3.0.
  - Подключение к Telegram: работа с `business_message` (Telegram Business API) и поддержка групповых чатов.
  - Анти-фрод Reels: алгоритм валидации URL, SHA-256 хеширование против дубликатов, HTTP HEAD probe.
  - AI-пайплайн: транскрибация голосовых (`.oga` -> текст) и выжимка фактов из бытового флуда.
  - Полная схема базы данных (DDL) и спецификация REST API.

* **`docs/ДОГОВОР_ПИСАРИК_СИДОРЕНКО.docx`** (а также `docs/CONTRACT_PISARIK_SIDORENKO.docx`) — Официальный документ Microsoft Word (.docx), полностью оформленный по академическим и деловым стандартам (Times New Roman 13 pt, абзацы 1.25 см, поля 30/15/20/20 мм, таблицы этапов и реквизитов, разделы ТЗ, Календарного плана и Акта сдачи-приемки).

* **`docs/CONTRACT_PISARIK_SIDORENKO.md`** — Официальный внешнеэкономический договор на заказную разработку ПО (Markdown-версия):
  - Исполнитель: ИП Писарик Мирослав Игоревич (Республика Армения).
  - Заказчик: Сидоренко Ксения Сергеевна (Республика Беларусь).
  - Приложение № 1: Техническое задание (ТЗ) на программный комплекс «Mentor Hub».
  - Приложение № 2: Календарный план и смета (5 этапов, 475 BYN).
  - Приложение № 3: Акт сдачи-приемки оказанных услуг.

* **`docs/CONTRACT_PRINT_READY.html`** / **`open-contract.bat`** — Готовая к печати и экспорту в PDF печатная версия договора (шрифт Times New Roman, стандарт A4, юридические формулировки, синяя гербовая печать ИП и подписи Сторон).

* **`docs/PITCH_PROPOSAL.md`** — Сценарий питча и коммерческое предложение для Ксении (по методологии direct-response копирайтинга):
  - Позиционирование по формуле BAB (Before — After — Bridge).
  - Сравнение пакетов: Базовый MVP (**320 BYN**) vs Полный PRO (**475 BYN**).
  - Отработка ключевых возражений («не разбираюсь в IT», «ученицы ленятся писать хэштеги», «зачем это, если есть Google Таблицы»).
  - Пошаговый сценарий демонстрации на созвоне за 7 минут.

```bash
# 1. Запуск через скрипт:
start-demo.bat

# 2. Либо вручную через консоль:
cd frontend
npm run dev
# Откройте в браузере: http://localhost:5173
```
